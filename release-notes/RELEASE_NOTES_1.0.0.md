# StarBurst v1.0.0 - Release Notes

Initial release of the StarBurst client.

## Highlights

- Native Material 3 chat interface with markdown, code blocks, and syntax highlighting
- Real-time message streaming with auto-scroll
- **On-device suggestions** — next-step prompts generated fully offline via a bundled MNN model,
  with optional external OpenAI-compatible LLM provider and silent fallback
- Workspace file browser with previews and downloads
- Full-screen terminal mode with PTY over WebSocket
- Session management with search, favorites, categorize, fork, share, export, and delete
- Completed-but-unread sessions pinned to the top of the session list
- Multi-server support with stable reconnection
- Adaptive two-pane layout on foldables and tablets
- Theme, dynamic color, AMOLED, and notification controls
- Secure in-app updates verified by SHA-256 and signing certificate
